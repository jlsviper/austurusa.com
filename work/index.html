Selected engineering work

Technical artifacts with explicit implementation status. A completed physical-design flow is different from manufactured silicon; a planned experiment is not a validated result.

EXP-004 — FIPE — Flexible Interface Protocol Emulator

Digital protocol timing characterization architecture, implemented in Hardcaml and routed for IHP 130 nm. The published timing/physical-check results apply to the documented verified snapshot, not automatically to later RTL revisions.

Implemented / routed · GitHub

EXP-005 — Formally Verified Power-Converter Controller

Proposed digital PWM architecture with a standalone safety kernel. The proof plan covers temporal pin commands; physical fail-safe behavior additionally requires clock, reset, driver, comparator, and PCB-level measures.

Planned research / no proofs yet

EXP-003 — Handheld Geiger Counter

Completed Geiger-Müller embedded instrument with conversion, signal processing, PCB, firmware, and comparative measurements. Full engineering report [PDF].

Built / tested
