Handheld Geiger Counter

EXP-003 · completed hardware experiment · 2022

Project report. Open the complete engineering report [PDF] →

purpose

Battery-powered Geiger-Müller radiation counter integrating high-voltage generation, embedded pulse acquisition, LCD readout, custom PCB hardware, and experimental calibration against a commercial reference instrument.

system

The instrument combines a rechargeable battery supply, regulated logic power, high-voltage generation for the Geiger-Müller tube, pulse conditioning, embedded count acquisition, and a character LCD user interface on a custom PCB.

validation

The completed hardware was brought up and bench-tested at the power, sensing, pulse-buffer, MCU, and display levels. Final calibration measurements were taken against a commercial reference Geiger counter using a controlled radiation source.

archive status

This is filed as a completed hardware experiment: the artifact includes physical implementation, measurement, calibration, and the full engineering report rather than a standalone research claim.
